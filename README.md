# 简历重写 · SODA

一个支持中英文简历改写的 Skill。基于目标岗位 JD，寻找真实经历中的对应证据与可迁移能力，输出清晰、突出贡献、便于复制使用的简历文本。

## SODA 方法

| 步骤 | 作用 |
| --- | --- |
| Scan | 拆解 JD，区分硬门槛、核心能力与加分项 |
| Overlap | 映射真实经历，区分直接匹配、可迁移经验与证据缺口 |
| Decode | 用目标岗位熟悉的语言表达能力，保持事实与业务范围不变 |
| Amplify | 调整重点与结构，突出已有量化成果 |

## 使用方式

将本仓库内容放入个人 Skills 目录下的 `resume-rewriter-soda` 文件夹。目录结构应为：

```text
resume-rewriter-soda/
├── SKILL.md
└── agents/
    └── openai.yaml
```

调用示例：

```text
请使用 $resume-rewriter-soda，根据以下简历和目标 JD 改写中文简历。

当前简历：……
目标岗位、级别与地区：……
目标 JD：……
必须保留的信息：……
```

没有 JD 时可直接润色简历或单条经历，不必提供所有信息。

## 输出

完整 JD 对标任务包括关键词地图、经历映射表、改写后的简历，以及必要的补充问题。单段润色只输出相关内容；可按要求提供最终稿或多个版本。

## 真实性原则

- 不虚构经历、职位、技能或数字。
- 不把「参与」升级为「主导」。
- 不把流程相似写成已具备目标行业经验。
- 缺少数据时提示补充，不预设改善结果。
- 直接投递的最终稿不保留未填写的占位符。
- 改善关键词覆盖与可读性，不保证 ATS 筛选结果。

完整行为说明见 [SKILL.md](SKILL.md)。
