# 简历重写 · SODA

一个支持中英文简历改写的 Skill。基于目标岗位 JD，寻找真实经历中的对应证据与可迁移能力，输出清晰、突出贡献、便于复制使用的简历文本。

## 为什么你的简历总是石沉大海？

很多伙伴明明有不错的项目经历，投出去却没什么回应。

问题可能出在：简历只交代了自己做过什么，却没有讲清楚，这些经历为什么能胜任目标岗位。

比如，有的简历写得像工作流水账，通篇都是“负责某某系统”“参与某某项目”，看不出具体用了什么方法、解决了什么问题。

还有的简历沿用了原行业的表达。同行看得懂，换一个领域，招聘方就未必能看出其中的关联。

尤其是跨行业求职，不能指望 HR 或筛选系统替我们把这些联系一一找出来。如果简历里没有写清楚，真实具备的能力也可能被忽略。

所以，这个 Agent 主要帮你处理几类问题：

**- 经历表达不清楚。**从“负责什么”往下多走一步，讲清楚采取了什么方法、产生了什么结果。
**- 简历与岗位不对齐。**找出与目标岗位相关的经历，把原本埋在后面的重点提到前面。
**- 跨行业能力难以识别。**到经历中相通的流程、方法和机制，用招聘方更容易理解的语言表达出来。

如果你已经有工作经历，需要针对不同岗位调整简历，或者正在考虑跨行业求职，这个 Agent 会比较适合你。

## SODA 方法

| 步骤 | 作用 |
| --- | --- |
| Scan | 拆解 JD，区分硬门槛、核心能力与加分项 |
| Overlap | 映射真实经历，区分直接匹配、可迁移经验与证据缺口 |
| Decode | 用目标岗位熟悉的语言表达能力，保持事实与业务范围不变 |
| Amplify | 调整重点与结构，突出已有量化成果 |

## 使用方式

将本仓库内容放入个人 Skills 目录下的 `resume-rewriter-soda` 文件夹。目录结构应为：

```text
resume-rewriter-soda/
├── SKILL.md
└── agents/
    └── openai.yaml
```

调用示例：

```text
请使用 $resume-rewriter-soda，根据以下简历和目标 JD 改写中文简历。

当前简历：……
目标岗位、级别与地区：……
目标 JD：……
必须保留的信息：……
```

没有 JD 时可直接润色简历或单条经历，不必提供所有信息。

## 输出

完整 JD 对标任务包括关键词地图、经历映射表、改写后的简历，以及必要的补充问题。单段润色只输出相关内容；可按要求提供最终稿或多个版本。

## 真实性原则

- 不虚构经历、职位、技能或数字。
- 不把「参与」升级为「主导」。
- 不把流程相似写成已具备目标行业经验。
- 缺少数据时提示补充，不预设改善结果。
- 直接投递的最终稿不保留未填写的占位符。
- 改善关键词覆盖与可读性，不保证 ATS 筛选结果。
